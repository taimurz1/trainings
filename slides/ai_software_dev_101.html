3 Coding Terms You Will Use Today

Glossary
1. Code Snippet: A short block of programming code that performs a specific task.
2. Debugging: Finding and fixing errors (bugs) that stop a program from running.
3. IDE / Code Editor: The software program (like VS Code or Visual Studio) where developers write code.

The 3-Step AI Coding Workflow

Process
1. DESCRIBE

Explain the exact page, SQL query, or feature you want.

2. GENERATE

AI builds the code snippet for you to review.

3. TEST & FIX

Run the code and paste error logs back if it crashes.

Step 1: Prompting AI to Write Code

Direct Comparison
❌ WEAK WAY ✅ RIGHT WAY
"Make a login form." "Write a simple HTML and CSS login form with fields for Email and Password, plus a green 'Submit' button."
🎯 Pro Tip: Always specify the programming language (e.g., C#, HTML, Python, SQL)!
AI Coding 101 Slide 6 of 10

Step 2: What to Do When Code Crashes

Debugging Guide
Step 1: Copy the red error message from your terminal or console.
Step 2: Paste the full error message into ChatGPT or Claude.
Step 3: Ask: "Why am I getting this error and how do I fix it?"
⚠️ Watch Out: Never panic when error text appears! AI will pinpoint the exact broken line number for you.
